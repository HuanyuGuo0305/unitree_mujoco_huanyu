# E1 paper assets (tracked copy)

These are copies of the official E1 outputs, so the published numbers are kept in git; `results/` is git-ignored. The source is `results/E1/`, and `results/E1/README.md` describes the data, the relocation and how to regenerate.

- `E1_500seed_tracking_rmse.tex`: the tracking table. It uses internal codes C1/C3/C5, which map to Unified RL (Ours), RL+IK and Cooperative RL.
- `E1_500seed_summary.csv`, `E1_500seed_paired_comparisons.csv`, `E1_500seed_completion_rates.csv`: the numbers behind the table.
- `E1_500seed_VALIDATION.md`: the validation record.
