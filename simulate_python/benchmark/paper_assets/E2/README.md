# E2 paper assets (tracked copy)

These are copies of the official E2 outputs, so the numbers are kept in git. The protocol is one dynamic condition with 100 paired seeds; see `E2_REPORT.md`. The source is `results/E2/`.

- `E2_summary_table.csv`: the four primary metrics for both modes, with paired differences, CIs and Holm p-values.
- `stats/`: per-mode statistics, all paired comparisons and completion.
- `validation/E2_validation.json`: the fairness and validity checks.

The publication table layout is not finalized.
