# Supplementary diagnostic figures (not for the main paper figure)

In both figures, the top row is the mean **signed** excess and the bottom row the post-hoc event-level mean **positive** excess. The positive part is taken per event, before averaging. Both use matched isolated switches and the per-event [−0.5, 0) s baseline.

- `supp_fig_e3_ee_switch_signed_vs_positive_excess.*`: EE-target switches, B = 0, T = 2 s. Base XY (left) and base yaw (right) error. 1,200 switches in 100 seeds.
- `supp_fig_e3_base_switch_signed_vs_positive_excess.*`: base-command switches, EE fixed, B = 0.60. EE position (left) and EE orientation (right) error. 652 switches in 90 seeds.

The top rows show why the main figure was changed: opposite-sign responses cancel in the signed mean, for RL+IK late after EE switches and for Cooperative RL after base switches.
