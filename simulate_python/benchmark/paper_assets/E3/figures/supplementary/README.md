# Supplementary diagnostic figures (not for the main paper figure)

`supp_fig_e3_base_switch_signed_vs_positive_excess.pdf/.png` (+ `_values.csv`):
isolated base-command switches, EE target fixed, B = 0.60, 652 matched switches in 90 seeds.

- **Top row:** mean *signed* excess EE position (left) and orientation (right) error. This is the v1 presentation.
- **Bottom row:** the post-hoc event-level mean *positive* excess. The positive part is taken per event, before averaging.

The top row shows why the main figure was changed: opposite-sign responses cancel in the signed mean, particularly for Cooperative RL.
Generated by `python3 -m benchmark.e3.paper_figures`.
